# MackieTranslator

轻量的 Windows 划词与截图翻译工具。选中文字，或框选屏幕上的文字，即可在同一窗口查看原文和译文。

**v1.0 · 首个正式发布版**

## 能做什么

- **划词翻译**：在支持取词的 PDF 阅读器、浏览器等应用中拖选或双击文字，自动取词并翻译；可随时暂停划词。
- **截图翻译**：框选屏幕区域，识别其中的文字，再生成译文；适用于无法直接选中文字的内容。
- **自动判断方向**：中文主要翻译为英文，英文、德语、意大利语等其他语言主要翻译为简体中文。混合语言、短词及生僻语言可能判断不准。
- **手动翻译**：支持输入、粘贴、编辑原文以及重新翻译。单词与长句均以译文呈现，不附带词典音标、词性或长篇解释。
- **多种服务**：默认提供 Bing；也可配置 DeepSeek、OpenAI、Kimi、通义千问、智谱 GLM、豆包、MiniMax。服务是否可用取决于网络、账号权限及模型能力。
- **翻译历史**：默认保存最近 20 条成功翻译，可复制译文、重新载入或清空；本机加密保存，重启后可恢复。
- **阅读体验**：支持窗口置顶、字体、字号、行距、主题、中英文界面，以及拖动调整原文和译文区域比例。
- **逐渐显示译文**：短译文渐进呈现，流式内容接续显示；长译文采用文字淡入，减少重复排版。
- **减少重复请求**：提供内存缓存、输入等待和重复请求合并；节省 Token 选项默认开启，尽量关闭模型的可选思考。不承诺固定节省比例。
- **本地自检**：可查看取词阶段、打开不联网的诊断报告，或启用临时“只取词、不联网”模式排查兼容问题。

## 下载与运行

在仓库的 **Releases** 中选择 v1.0：

| 文件 | 用途 |
| --- | --- |
| `MackieTranslator-v1.0-Setup.exe` | 安装版，默认安装到系统 Program Files，可修改路径 |
| `MackieTranslator-v1.0-Portable.zip` | 便携版，完整解压后运行 `MackieTranslator.exe` |
| `MackieTranslator-v1.0-Source.zip` | 源码与构建说明 |

面向 Windows x64，依赖 .NET Framework 4.8；截图的本地 OCR 还依赖 Windows OCR 组件及识别语言。优先在 Windows 10/11 上使用；没有完成所有系统版本的实测。便携版请保留 DLL、配置文件和许可证目录，不要只复制主程序。

## 开始使用

1. 启动程序，确认右上角显示“划词：已开启”。
2. 在其他应用中选中文字，等待自动取词与翻译；也可直接粘贴内容。
3. 点击“截图翻译”，拖动框选文字，松开鼠标后识别；按 Esc 或右键可取消框选。
4. 如需使用 AI 服务，在“设置 → 翻译服务”选择服务，填写自己的密钥和模型并保存。
5. 识别或翻译有误时，先核对原文，再修改原文重新翻译。

## 截图识别：建议配置 AI 服务

**默认 Bing 模式的截图识别可能不准确，建议配置其他支持图像识别的 API 服务。**

Bing 模式使用 Windows 本地 OCR：识别效果受截图清晰度、字体、排版和已安装 OCR 语言影响，少数语言尤其可能误识别或无法识别。AI 服务模式将框选图片发送给所选服务支持图像输入的模型，提取原文后再进行文字翻译，不会静默切回 Windows OCR。

AI 也可能识别错误，尤其是模糊文字、专业符号、生僻语言及上下文不足的短词；请核对重要内容。截图识别与后续翻译是两个步骤，AI 模式可能产生两次请求的费用。不同账号和模型的图片输入权限可能不同。

## 安全与隐私

- **密钥本机加密保存**：使用 Windows DPAPI，绑定当前 Windows 用户；各 API 服务单独配置，Bing 不接收 AI 服务密钥。程序请求所选服务时仍需在内存中使用密钥。
- **明确数据去向**：普通翻译将原文发送给所选服务；AI 截图识别会发送整个框选区域的 PNG 图片；Bing 模式图片在本机识别，仅将识别文字提交在线翻译。请避免框入账号、聊天、密钥等不需要翻译的内容。
- **历史与缓存**：历史在当前用户目录加密保存；翻译、截图识别缓存只在内存中，不跨会话保存。截图图片不会由程序自动写入磁盘或剪贴板。
- **接口约束**：AI 请求仅允许与所选服务匹配的预设官方 HTTPS 主机；保留证书校验，禁用自动重定向和隐式 Windows 身份验证。
- **有限的敏感内容拦截**：自动翻译会尝试跳过已配置密钥及部分常见密钥、私钥格式。这不是完整的数据防泄漏系统，不能保证识别所有敏感内容。
- **诊断与发布包**：正常运行不将原文、译文或密钥写入诊断事件；本地报告记录阶段和计数，不自动上传。发布包只包含程序、运行库、文档和许可证，不包含作者个人配置、密钥或翻译历史。

本机加密不能抵御已控制当前用户会话的恶意程序；云服务可能按各自条款处理提交的数据。软件没有自动更新、远程字体下载或遥测模块。详见 [安全说明](SECURITY.md)。

## 发布前修复与验证

v1.0 整理了划词与截图切换、历史持久化、旧请求取消、无文字截图、服务请求格式和界面布局等修复。

- **真实操作确认**：截图翻译完成后，不先点击福昕，直接拖选新的英文，原文更新并自动翻译；该流程由用户在本机确认通过。
- **自动检查**：433 项界面检查、314 项优化检查、241 项离线接口检查，以及 17 项可靠性检查通过；还验证了 Windows 实际加密往返、历史保存/重载/清空和取词启停退出。
- **截图检查**：多语言 OCR 流程检查通过；AI 接口部分使用模拟响应，不能据此证明云端识别准确率。Windows OCR 样例仍有字符误识别。

这些数字是测试断言数量，不是软件兼容数量，也不是“修复了同样多的 BUG”。没有完成所有 PDF 软件、系统、显示器配置和真实 API 账号的全面测试。详细范围、已知限制与复测方法见 [发布前测试记录](TESTING.md)。

## 常见问题

**划词没反应？** 确认未暂停，PDF 本身允许复制，目标程序与翻译程序权限一致。尝试“设置 → 阅读与划词 → 取词自检”，再查看本地诊断。扫描件、受保护内容或不支持选区接口的软件，可尝试截图翻译；不能保证任意应用均可取词。

**译文错误？** 先检查原文是否识别正确，再检查翻译方向、服务和模型。模型不一定了解生僻语言；重要文本请人工核对。

**便携版换电脑后密钥失效？** 设置与历史保存在当前用户的本地配置目录，不随便携程序目录迁移；DPAPI 数据也不能保证跨用户、跨电脑解密。请在新电脑重新配置密钥。

**有哪些暂未提供？** 暂无全局截图快捷键、图片原位覆盖翻译、离线 AI 翻译或云端历史同步。
