MackieTranslator v1.0 — 首个正式版

Windows 划词、截图与手动翻译工具。
完整解压后运行 MackieTranslator.exe，保留 DLL、配置和许可证目录。

中文主要译英文，其他语言主要译简体中文。
支持 Bing，以及配置自己的 DeepSeek、OpenAI、Kimi、通义千问、智谱 GLM、豆包、MiniMax API。
历史默认20条，本机加密保存。支持主题、字体、字号、行距、窗口置顶和本地诊断。

默认 Bing 截图使用 Windows OCR，可能不准确，建议使用支持图像识别的其他 API 服务。AI 也可能出错，且会将框选图片提交所选服务，可能收费。
密钥使用 Windows 当前用户 DPAPI 本机保护；不要翻译或截图不必要的秘密信息。取词可能改变剪贴板。发布包不包含作者密钥、配置或个人历史。

完整功能、运行要求和数据去向见 README.md、SECURITY.md。
发布前 BUG 修复、测试与局限见 TESTING.md。
